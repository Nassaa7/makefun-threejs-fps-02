Emberline is a round-based tactical FPS in the browser: plant or defend the charge across a dockside container yard, earn money between rounds, and out-aim seven bots that hold angles, follow routes, and react to what they see and hear. It runs offline from static files on three.js, with procedural art and sound — no assets, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
